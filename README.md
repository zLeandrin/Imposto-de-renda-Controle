# 🧾 Organizador de Imposto de Renda

Planilha em Excel para reunir, em um só lugar, as informações necessárias na hora de fazer a declaração do Imposto de Renda: dados pessoais, informes de rendimentos dos bancos e entradas de receita mês a mês.

O arquivo tem um menu lateral para navegar entre as abas, sem precisar procurar nada nas guias da planilha.


## ✨ Funcionalidades

- **Menu lateral de navegação** com botões que levam direto para cada aba (Titular, Notas e Informes).
- **Dados do titular:** nome, CPF, nascimento, título de eleitor, cônjuge, endereço, CEP, celular e e-mail.
- **Perguntas de Sim/Não** com lista suspensa (alterações da entrega anterior, dependente cônjuge e residente do exterior).
- **Informes de rendimentos bancários:** para cada banco, escolha a instituição em uma lista, informe o valor atual e registre o nome do arquivo do informe.
- **Total automático** dos valores informados na aba Informes.
- **Notas bancárias / holerites:** tabela para lançar data, categoria e valor das entradas de receita.
- **Lista de bancos e categorias** prontas na aba de apoio (`dados bancos`).
- **Links de contato** do autor (LinkedIn e GitHub) no rodapé do menu.

## 📂 Estrutura da planilha

| Aba | Para que serve |
|---|---|
| **Titular** | Cadastro dos dados da pessoa física. |
| **Informes** | Informes de rendimentos por banco, com valor atual, anexo e total geral. |
| **Notas** | Lançamento das entradas de receita (data, categoria e valor), mês a mês. |
| **dados bancos** | Listas de apoio usadas nos campos de seleção: bancos e categorias de receita. |

### Categorias de receita disponíveis

Salário, Pró-labore, Aposentadoria, Aluguel Recebido e Serviço Autônomo.

## 🛠️ Tecnologias

- Microsoft Excel (formas com hiperlinks internos, tabelas, validação de dados e fórmulas)
